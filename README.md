# CarePath

CarePath is a portfolio prototype for an online consultation funnel. It uses static HTML, CSS, and JavaScript.

- [Guided version](https://wesbertolaia.github.io/carepath/) lets visitors pick a question before they see the intake preview.
- [Direct version](https://wesbertolaia.github.io/carepath/?path=direct) takes visitors straight to the same intake preview.
- [Case study](https://wesbertolaia.github.io/portfolio/#carepath) explains the hypothesis, the primary metric, and the guardrails.

The demo asks no personal or medical questions. The optional event log shows what happened on the current page and sends nothing to an analytics service. The two links are manually selected variants. A real experiment would require random assignment and traffic.

Open `index.html` to run locally.
